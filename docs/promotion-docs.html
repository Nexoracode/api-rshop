سیستم پروموشن فروشگاه v1 · Internal

این مستند نحوه تعریف، مدیریت و استفاده از پروموشن‌ها (کوپن تخفیف، پیشنهاد شگفت‌انگیز، ارسال رایگان، خرید اول و پاداش خرید بعدی) را در بک‌اند فروشگاه توضیح می‌دهد.

POST بررسی و اعمال پروموشن روی سفارش

/promotions/check

این متد برای مرحلهٔ Checkout استفاده می‌شود؛ براساس سبد خرید و اطلاعات کاربر، تخفیف و ارسال رایگان محاسبه می‌شود. اگر code ارسال شود، فقط همان کوپن بررسی می‌شود؛ در غیر این‌صورت همهٔ پروموشن‌های فعال روی سفارش تست می‌شوند.

Request Body
نمونه ورودی برای محاسبهٔ پروموشن روی سفارش
typeJSON 
{
  "userId": 100,
  "code": "OFF20",
  "subtotal": 300000,
  "shippingCost": 30000,
  "isFirstOrder": false,
  "items": [
    {
      "productId": 12,
      "categoryId": 5,
      "quantity": 1,
      "unitPrice": 300000
    }
  ]
}
Response
خروجی نهایی پس از اعمال پروموشن‌ها
200OK 
{
  "discount": 60000,
  "freeShipping": false,
  "finalShipping": 30000,
  "finalTotal": 270000,
  "appliedPromotionIds": [3]
}
فیلد توضیح
discount مجموع مبلغ تخفیف اعمال‌شده روی سفارش
freeShipping اگر true باشد یعنی هزینهٔ ارسال صفر شده است
finalShipping هزینهٔ نهایی ارسال پس از پروموشن
finalTotal مبلغ نهایی پرداختی کاربر
appliedPromotionIds آیدی پروموشن‌هایی که روی سفارش اعمال شده‌اند

POST ساخت پروموشن جدید

/admin/promotions

این متد در پنل ادمین استفاده می‌شود و امکان تعریف انواع پروموشن (کوپن تخفیف، پیشنهاد شگفت‌انگیز، ارسال رایگان، خرید اول و پاداش خرید بعدی) را به شما می‌دهد.

Coupon – تخفیف درصدی روی محصول مشخص
type = coupon · تخفیف ۲۰٪ روی محصول ۱۲
Example A 
{
  "name": "20% OFF Product 12",
  "type": "coupon",
  "code": "OFF20P12",
  "startsAt": "2025-01-01 00:00:00",
  "endsAt": "2025-12-31 23:59:59",
  "usageLimit": 100,
  "isActive": true,
  "conditions": [
    { "type": "product", "productIds": [12] }
  ],
  "actions": [
    { "type": "percent_discount", "value": 20 }
  ]
}
Coupon – تخفیف مبلغی مخصوص یک کاربر
type = coupon · تخفیف ۷۰هزار تومانی فقط برای userId=322
Example B 
{
  "name": "70,000 OFF for User 322",
  "type": "coupon",
  "code": "REZA70",
  "startsAt": "2025-01-01 00:00:00",
  "endsAt": "2025-12-31 23:59:59",
  "conditions": [
    { "type": "user", "userId": 322 }
  ],
  "actions": [
    { "type": "amount_discount", "value": 70000 }
  ]
}
Flash Deal – پیشنهاد شگفت‌انگیز دسته
type = flash_deal · تخفیف ۱۵۰هزار روی categoryId=5
Example C 
{
  "name": "Flash Deal Perfumes",
  "type": "flash_deal",
  "startsAt": "2025-02-10 00:00:00",
  "endsAt": "2025-02-20 23:59:59",
  "conditions": [
    { "type": "category", "categoryIds": [5] }
  ],
  "actions": [
    { "type": "amount_discount", "value": 150000 }
  ]
}
Free Shipping – ارسال رایگان بالای مبلغ مشخص
type = free_shipping · ارسال رایگان بالای ۵۰۰هزار تومان
Example D 
{
  "name": "Free shipping over 500k",
  "type": "free_shipping",
  "startsAt": "2025-01-01 00:00:00",
  "endsAt": "2030-01-01 00:00:00",
  "conditions": [
    { "type": "min_order_amount", "minAmount": 500000 }
  ],
  "actions": [
    { "type": "free_shipping" }
  ]
}
First Order – تخفیف خرید اول
type = first_order · تخفیف ۱۵٪ مخصوص اولین سفارش
Example E 
{
  "name": "15% OFF First Order",
  "type": "first_order",
  "startsAt": "2025-01-01 00:00:00",
  "endsAt": "2026-01-01 00:00:00",
  "conditions": [
    { "type": "first_order" }
  ],
  "actions": [
    { "type": "percent_discount", "value": 15 }
  ]
}
Next Order Reward – پاداش خرید بعدی
type = next_order_reward · صدور کوپن برای سفارش بعدی
Example F 
{
  "name": "Next Order Reward 50k",
  "type": "next_order_reward",
  "startsAt": "2025-01-01 00:00:00",
  "endsAt": "2026-01-01 00:00:00",
  "conditions": [
    { "type": "min_order_amount", "minAmount": 400000 }
  ],
  "actions": [
    {
      "type": "next_order_coupon",
      "meta": { "rewardAmount": 50000 }
    }
  ]
}

GET لیست پروموشن‌ها (پنل ادمین)

/admin/promotions

این متد برای لیست کردن پروموشن‌ها در پنل ادمین با پشتیبانی از صفحه‌بندی، جستجو و فیلترها استفاده می‌شود.

Query Params
نمونهٔ فراخوانی با فیلتر
GET /admin/promotions?page=1&limit=20&search=off&type=coupon&status=active
پارامتر نوع توضیح
page number شماره صفحه (پیش‌فرض: 1)
limit number تعداد در هر صفحه (پیش‌فرض: 20)
search string جستجو روی فیلد name
type string فیلتر بر اساس PromotionType (مثلاً: coupon, flash_deal, ...)
isActive boolean true / false
status string active / expired / upcoming
Response
ساختار خروجی صفحه‌بندی
{
  "items": [
    {
      "id": 1,
      "name": "Flash Deal Perfumes",
      "type": "flash_deal",
      "code": null,
      "startsAt": "2025-02-10T00:00:00.000Z",
      "endsAt": "2025-02-20T23:59:59.000Z",
      "isActive": true
    }
  ],
  "total": 1
}

PUT ویرایش پروموشن

/admin/promotions/:id

برای به‌روزرسانی نام، وضعیت، شروط یا اکشن‌های یک پروموشن استفاده می‌شود. بدنهٔ درخواست همان ساختار CreatePromotionDto را به‌صورت partial دارد.

Request نمونه
افزایش مقدار تخفیف در یک فلش دیل
{
  "name": "Flash Deal Perfumes (Updated)",
  "actions": [
    { "type": "amount_discount", "value": 200000 }
  ]
}

DELETE حذف پروموشن

/admin/promotions/:id

حذف پروموشن از سیستم. این عملیات رکورد پروموشن و شروط/اکشن‌های مرتبط را حذف می‌کند (Cascade).

نمونه
حذف پروموشن با آیدی 5
DELETE /admin/promotions/5

انواع PromotionType

نوع کلی پروموشن که رفتار اصلی آن را تعیین می‌کند. این نوع در فیلد type در پروموشن استفاده می‌شود.

مقدار توضیح
coupon کد تخفیف مبتنی بر کوپن (دارای فیلد code)
flash_deal پیشنهاد شگفت‌انگیز (برای نمایش در صفحهٔ اصلی/لیست‌ها)
free_shipping پروموشن‌های مربوط به ارسال رایگان
first_order تنها برای اولین سفارش کاربر
next_order_reward اعطای پاداش (کوپن) برای خریدهای بعدی

انواع ConditionType

هر پروموشن می‌تواند یک یا چند شرط داشته باشد؛ تمام شروط باید برقرار باشند تا پروموشن روی سفارش اعمال شود.

مقدار فیلدهای مرتبط توضیح
user userId محدود کردن پروموشن برای یک کاربر مشخص
product productIds اعمال پروموشن فقط روی سفارش‌هایی که شامل محصولات خاصی هستند
category categoryIds محدود به محصولات داخل دسته‌بندی‌های مشخص
min_order_amount minAmount حداقل مبلغ سفارش برای فعال شدن پروموشن
first_order - تنها برای اولین سفارش (با فیلد isFirstOrder در Request کنترل می‌شود)

انواع ActionType

هر اکشن مشخص می‌کند که بعد از برقرار بودن شروط، چه نوع تخفیف/اثری روی سفارش اعمال شود. یک پروموشن می‌تواند چند اکشن همزمان داشته باشد.

مقدار فیلدهای مرتبط توضیح
percent_discount value اعمال تخفیف درصدی روی مبلغ سبد خرید
amount_discount value اعمال تخفیف مبلغ ثابت روی سبد خرید
free_shipping - رایگان کردن هزینهٔ ارسال (shippingCost = 0)
next_order_coupon meta.rewardAmount (و سایر تنظیمات داخل meta) صدور یک کوپن جدید برای سفارش‌های بعدی کاربر پس از تکمیل این سفارش
