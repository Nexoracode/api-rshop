🎠 بخش ۱: اسلایدر اصلی (Hero Slider)

🎠

اسلایدر بزرگ صفحه اصلی

اسلایدر تمام عرض با ارتفاع حدود 500px

📋 توضیحات

اسلایدر اصلی در بالای صفحه قرار می‌گیرد و معمولاً برای:

  • تبلیغات محصولات ویژه
  • معرفی کمپین‌ها و تخفیف‌های ویژه
  • اطلاع‌رسانی‌های مهم
  • جذب توجه کاربران جدید

✨ ویژگی‌های طراحی

  • Auto-play: تغییر خودکار هر 5 ثانیه
  • Navigation: فلش‌های چپ/راست برای تغییر دستی
  • Dots: نقاط پایین برای نمایش موقعیت و کلیک
  • Hover Effect: توقف auto-play هنگام hover
  • Responsive: در موبایل به صورت عمودی نمایش داده شود

📡 Hero Slider - API و داده‌ها

ساختار JSON

{
  "heroSliders": [
    {
      "id": 1,
      "title": "تسبیح تایگر چشم بین",
      "description": "محصول دست‌ساز با کیفیت عالی",
      "imageUrl": "/uploads/sliders/slider1.jpg",
      "backgroundColor": "#E8B4D9",
      "buttonText": "مشاهده محصول",
      "buttonLink": "/products/tiger-eye-tasbih"
    },
    ...
  ]
}

📊 فیلدها

فیلد نوع توضیحات
id number شناسه یونیک - برای analytics
title string عنوان اصلی - فونت بزرگ و Bold
description string | null توضیحات کوتاه - اختیاری
imageUrl string آدرس تصویر محصول
backgroundColor string رنگ پس‌زمینه (مثلاً #E8B4D9)
buttonText string | null متن دکمه - اختیاری
buttonLink string | null لینک دکمه - اختیاری
💡 نکته: اگر buttonText و buttonLink مقدار داشتند، دکمه نمایش داده می‌شود. در غیر این صورت فقط عنوان و توضیحات.

🎨 Hero Slider - راهنمای طراحی

ابعاد و اندازه‌ها

  • ارتفاع: 500px (Desktop) / 400px (Mobile)
  • عرض: 100% (تمام عرض کانتینر)
  • Border Radius: 16px
  • Padding داخلی: 60px (Desktop) / 30px (Mobile)

رنگ‌ها و فونت‌ها

  • عنوان: 42px, Bold, رنگ #1a202c
  • توضیحات: 18px, Normal, رنگ #4a5568
  • دکمه: پس‌زمینه #2563eb, متن سفید, Padding 14px 32px
  • Navigation Arrows: دایره سفید با سایه
  • Dots: سفید شفاف، فعال: سفید کامل
⚠️ نکات مهم:
  • حتماً transition نرم برای تغییر اسلایدها (0.5s)
  • تصویر باید aspect ratio حفظ کند
  • در موبایل، محتوا و تصویر زیر هم قرار گیرند
  • دکمه باید وقتی hover میشه، بالا بیاد (translateY)

🎫 بخش ۲: بنرهای کناری (Side Banners)

🎫

بنرهای کوچک کناری

بنرهای 320px عرض در سمت راست صفحه

📋 توضیحات

بنرهای کناری در سمت راست صفحه قرار می‌گیرند و در سه موقعیت مختلف نمایش داده می‌شوند:

📍 موقعیت‌ها

  • top_right: بالای سمت راست (کنار اسلایدر)
  • middle_right: وسط سمت راست (کنار دسته‌بندی‌ها)
  • bottom_right: پایین سمت راست (کنار بخش اول)

✨ ویژگی‌های طراحی

  • عرض ثابت: 320px در Desktop
  • Badge تخفیف: در گوشه (اگر داشته باشد)
  • Hover Effect: بالا آمدن با سایه
  • Responsive: در موبایل تمام عرض
  • چند بنر: می‌توان چند بنر در یک موقعیت داشت

🎨 ساختار یک بنر

│                      │
│                      │

│                      │
│                      │
├──────────────────────┤
│  عنوان بنر           │  ← عنوان اصلی
│  محدوده قیمت         │  ← زیرعنوان
└──────────────────────┘

📊 فیلدها

فیلد نوع توضیحات
id number شناسه یونیک

imageUrl string آدرس تصویر

position enum top_right | middle_right | bottom_right
badgeText string | null متن برچسب (مثل 14%)
badgeColor string | null رنگ برچسب (Hex Color)

🎨 Side Banners - راهنمای طراحی

ابعاد و اندازه‌ها

  • عرض: 320px (Desktop) / 100% (Mobile)
  • ارتفاع تصویر: 200px
  • Border Radius: 12px
  • فاصله بین بنرها: 16px

رنگ‌ها و فونت‌ها

  • عنوان: 18px, Bold, رنگ #1e293b
  • زیرعنوان: 14px, Normal, رنگ #64748b
  • Badge: 14px, Bold, سفید روی رنگ مشخص شده
  • Hover: translateY(-4px) + سایه بزرگتر

📦 بخش ۴: بخش‌های محصولات (Home Sections)

📦

بخش‌های مختلف محصولات

نمایش محصولات به روش‌های مختلف

📋 توضیحات

هر بخش شامل:

  • هدر: عنوان، توضیحات، دکمه "مشاهده همه"
  • محصولات: لیست محصولات با استایل مشخص
  • استایل نمایش: Carousel یا Grid یا List

📑 انواع بخش‌ها (Section Types)

۱. featured - محصولات ویژه

محصولاتی که با علامت ویژه مشخص شده‌اند (isFeatured = true)

  • به صورت خودکار انتخاب می‌شوند
  • معمولاً در بالای صفحه
  • پیشنهاد: استایل Carousel

۲. special_products - محصولات دستی

محصولاتی که ادمین به صورت دستی انتخاب کرده

  • کنترل کامل روی محصولات
  • برای کمپین‌های خاص
  • پیشنهاد: استایل Grid

۳. most_popular - محبوب‌ترین

محصولات بر اساس تعداد فروش (sold_count)

  • مرتب‌سازی نزولی (پرفروش‌ترین اول)
  • بروزرسانی خودکار
  • پیشنهاد: استایل Grid یا Carousel

۴. category_based - دسته‌بندی محور

محصولات یک دسته‌بندی خاص

  • برای معرفی دسته
  • جدیدترین محصولات آن دسته
  • پیشنهاد: استایل Grid

Response:

  "sideBanners": [...],

💡 کش: این API به مدت 5 دقیقه کش می‌شود، پس نیازی به نگرانی برای بار سرور نیست.

📊 API Analytics - ثبت کلیک‌ها

POST /home/analytics/track/:type/:id

توضیح: ثبت کلیک کاربر روی اسلایدر یا بنر

Parameters:

  • type: نوع عنصر → hero_slider یا side_banner
  • id: شناسه عنصر

مثال:

POST /home/analytics/track/hero_slider/1
POST /home/analytics/track/side_banner/5
💡 نکته: IP و User-Agent به صورت خودکار ثبت می‌شوند. نیازی به ارسال Body نیست.

📝 نحوه پیاده‌سازی

هر وقت کاربر روی اسلایدر یا بنر کلیک کرد، درخواست POST ارسال کنید: 

// وقتی روی اسلایدر کلیک شد
onClick: () => {
  fetch('/home/analytics/track/hero_slider/' + sliderId, { method: 'POST' });
  // سپس به لینک هدایت شود
}
⚠️ مهم: اگر درخواست Analytics با خطا مواجه شد، نباید مانع ادامه کار شود. فقط یک console.warn بزنید.
