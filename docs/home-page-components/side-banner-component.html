🎫 Side Banner Component

نمونه کامل بنرهای کناری با سه موقعیت مختلف

📡 اتصال به API

این کامپوننت داده‌های خود را از API زیر دریافت می‌کند:

GET /home

نکته: داده‌های بنرها در فیلد sideBanners قرار دارند.

📦 ساختار داده

{
  "id": 1,
  "title": "عنوان بنر",
  "subtitle": "زیرعنوان یا قیمت",
  "imageUrl": "/uploads/banner.jpg",
  "link": "/category/quran",
  "position": "top_right",      // top_right | middle_right | bottom_right
  "badgeText": "14%",            // اختیاری
  "badgeColor": "#FF0000"        // اختیاری
}

📍 انواع موقعیت (Position)

مقدار توضیحات
top_right بالای سمت راست صفحه
middle_right وسط سمت راست صفحه
bottom_right پایین سمت راست صفحه

محتوای اصلی صفحه

این بخش نشان‌دهنده محتوای اصلی صفحه شماست. بنرهای کناری در سمت راست این محتوا قرار می‌گیرند.

معمولاً در این قسمت اسلایدر اصلی، دسته‌بندی‌ها و بخش‌های مختلف محصولات نمایش داده می‌شوند.

بنرهای کناری برای تبلیغات، معرفی دسته‌بندی‌ها یا نمایش تخفیف‌های ویژه استفاده می‌شوند.

💻 نحوه استفاده

// 1. دریافت داده‌ها
const response = await fetch('API_URL/home');
const data = await response.json();

// 2. رندر بنرها
renderSideBanners(data.sideBanners);

// 3. یا استفاده از تابع آماده
loadBanners();
